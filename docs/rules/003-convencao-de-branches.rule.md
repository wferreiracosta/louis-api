# Convenção de Branches

---

## Formato

```
<tipo>/<numero_issue>
```

**Exemplo:**

```
feat/16
fix/3
docs/17
```

---

## Regras

- O `<tipo>` deve ser o mesmo tipo usado na convenção de commits (ver [`002-convencao-de-commits.rule.md`](./002-convencao-de-commits.rule.md))
- O `<numero_issue>` corresponde ao número da issue ou do plano de melhoria associado
- Use apenas letras minúsculas e sem espaços
